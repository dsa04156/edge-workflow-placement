# 선택적 프로파일링 첫 합성 검증

2026-10-21. 상태: 첫 합성 구현·검증 완료. 범위는 설계 v0.1의 작은 합성 비용모형이며 실제 장비·클러스터 실험과 신규성 입증은 아니다. 최초·수정 중간 결과도 보존했다.

## 결론

**공유 비용 상쇄 사례에서는 측정 절감이 보였지만, 제안 규칙의 일반적인 우월성은 확인되지 않았다.** 비싼 필수 측정을 미루는 현상과 순차 p75 구간의 큰 측정 부담이 구체적인 한계로 드러났다. 현재 단계에서 더 큰 모델이나 실제 클러스터로 바로 확대할 근거는 부족하다.

## 구현·실험 계약

[설계](decision-focused-placement-design-20261021.md)를 [표준 라이브러리 Python 모듈](../../experiments/decision-focused-placement/README.md)로 구현했다. 작은 box에서 Fraction 유리수 LP의 전체 vertex를 열거하여 정확한 pairwise regret를 검증한다. 완료하지 못하면 간단한 유효 상한을 유지한다. 모든 경쟁 배치를 포함한 종료 검증과 측정 선택 휴리스틱은 분리했다.

6개 fixture × 4개 규칙 × 5개 seed = 120회. 각 fixture는 2개 배치·최대 2개 primitive이며, 현재 실제 19배치 문제의 실측 재현은 아니다. 허용 proxy gap ε=1, δ=.05, 한 probe는 20개 표본 batch, 최대 150 probe. 동일 arm별 표본 흐름을 사용하되 각 정책에는 요청한 표본만 공개한다. 분포의 참 p75는 평가자만 사용한다. 최초 결과 확인 뒤 fixture·예산을 바꾸지 않았다.

정책은 순환 균등, 구간 폭/비용, incumbent–witness 최대 구간 폭, 제안 contrast-width/비용이다. 후자의 매5회 순환 측정도 설계대로 고정했다. 기존 논문의 아이디어를 옮긴 기준선이며 원 구현 재현이 아니다. 모든 규칙에 같은 전체-regret 종료 검증을 사용한다.

## 최초 관측 결과

아래 횟수는 **표본 수가 아니라 20개 표본을 받는 probe batch의 평균**이다. 가상 비용은 fixture에 정한 획득 비용의 합이고 실제 클러스터 시간 절감이 아니다.

| 조건 | 비교 결과 | 해석 |
|---|---|---|
| 공유 가산 비용 | 균등 40.8회·가상 비용102.0 → 제안 22.6회·29.2. 둘 다 5/5 인증 | 이 사례에서 비용 약71.4% 감소. 결정에 무관한 공통 지연을 덜 측정한 효과 |
| 임계경로 전환 | 폭/비용·witness 101.6회, 제안110.0회. 각각5/5 인증 | 제안이 더 많이 측정함 |
| 근소한 성능 차이 | 모든 규칙150회, 모두0/5 인증 | 실제 참 gap은0이어도 순차 구간이 넓어 종료 보장을 얻지 못함 |
| 필수 측정 비용10배 | 균등3/5, witness2/5, 폭/비용0/5, 제안0/5 인증 | 비용 정규화가 필요한 비싼 항목을 미룸. 제안의 순환 보완도 해당 예산에서 부족 |
| 대칭·이점 없는 조건 | 모든 규칙16.0–16.4회,5/5 인증 | 사실상 동률 |
| timeout 검열 | 모든 규칙0/5 인증, 검열 종료 | 검열용 신뢰구간을 구현하지 않았으므로 의도된 미인증 |

인증된 실행에서 참 proxy gap>ε 사례는 0이었다. 소수 seed의 결과로 이론상 δ 실패확률을 검증한 것은 아니다. 미인증 실행에서는 witness가 공유 비용 사례에서 참 gap3, 폭/비용이 비싼 측정 사례에서 gap5인 배치를 고르기도 했다. **미인증 추천과 허용 오차 내 선택을 구분해야 한다.**

최초 실행 전체 약3.43초, 실행별 실제 planner 시간 최대 약0.11초였다. 큰 배치 집합에서 계획 비용이 병목인지, 가상 획득 비용이 실제 프로파일링 시간과 맞는지는 확인하지 않았다. 직접 구성한 작은 fixture의 선택 편향도 있다.

## 설계에 대한 함의

1. `b=argmin L(p;u)`는 최악 regret가 작은 배치를 찾는 규칙과 다르다. 설계의 경로 전환 예에서 p의 상한비용50이 q의52보다 작아 p를 고르지만, R(p)=10이고 R(q)=2다. 다른 후보도 검증하면 일찍 종료할 가능성이 있으나 추가 계산 비용을 비교해야 한다.
2. 단순한 불확실성/비용 비율은 비싼 필수 항목을 계속 미룰 수 있다. 고정 순환 주기의 보완 효과도 제한적이다. 다음 후보는 필요한 항목에 측정 기회를 보장하는 기존 pure-exploration 기준선부터 대조해야 한다.
3. 경험 성능이 좋아도 DKW 인증 비용은 클 수 있다. 목적 통계량·순차 보장·실제 지연모형의 불일치를 해결하지 않고 예산만 키우면 연구 주장의 근거가 되지 않는다.

이 세 가지는 관측된 문제와 후속 검토 방향이다. 새 알고리즘의 신규성 또는 기존 연구의 미지원 조건이라고 주장하지 않는다.

- **Spec:** 두 번째 독립 검토에서 기존4건 해결을 확인하고 미사용 무한 좌표의 acquisition crash 1건을 추가 발견했다. Claude가 이 경계 사례를 수정했고 호스트가 실제 수정과 회귀 테스트를 확인했다. 독립 검토는 지침대로2회로 끝냈으며, 마지막 수정에 세 번째 독립 승인까지 받았다고 주장하지 않는다.
- 알려진 구현 결함은 이 범위에서 모두 처리했다. planner 예산의 checkpoint 방식, float DKW 계산, 검열 미인증, 작은 합성 fixture·seed의 한계는 유지된다.
