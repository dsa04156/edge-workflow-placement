# 배치 결정을 위한 선택적 프로파일링 설계 v0.1

작성일: 2026-10-21. 상태: 연구 설계 완료, 구현·새 실측 없음, 신규성 미입증.

후속 상태: 이 문서는 최초 설계 시점의 기록이다. 이후 [첫 합성 구현·검증](decision-focused-placement-synthetic-20261021.md)을 완료했다. 실제 클러스터 측정과 신규성 검증은 완료하지 않았다.

## 설계 결정과 범위

고정된 DAG·모델·엣지 source·실행 환경에서 **배치 선택에 영향을 주는 비용부터 측정하고, 비용모형 안의 선택 손실 상한이 허용치 이하이면 측정을 종료**한다. 현재 3Task·19개 실행 가능 배치는 정확 열거를 유지한다. 연구할 대상은 측정 선택 규칙과 그 계산 비용이다. 운영 중 재배치나 환경 변화 대응 보장은 이번 설계에 포함하지 않는다.

앞선 [국소 탐색 신규성 검토](static-placement-novelty-review-20261021.md)에서 기존 LNS·부분 최적화·교환과의 중복이 확인됐다. 따라서 기존 후보를 독립적인 새 알고리즘으로 주장하지 않는다. 이번 설계 역시 기존 minimax-regret elicitation과 structured pure exploration의 적용 후보다. 검증할 가설은 **공유 비용의 상쇄와 임계경로 전환을 반영한 저비용 측정 선택이 기존 선택 규칙보다 측정·계획의 총 시간을 줄이는가**이다.

## 입력·출력과 관측 계약

입력은 DAG, 모델/산출물 hash, 고정 source, 입력 분포·bytes, 검증된 runtime 후보, CPU·메모리·상주 슬롯 제약, probe 목록, 허용 오차 ε(ms), 실패확률 δ, 측정·계획 시간 예산이다. 품질·호환성 검증으로 실행 가능 집합 F를 먼저 동결한다. 선택적 측정을 이유로 필수 품질 검증을 생략하지 않는다.

출력은 선택 배치, proxy regret 상한, `proxy_certified`, 종료 이유, primitive별 표본 수·구간, probe/준비/계획 시간, timeout·실패 기록, 재현 manifest다. 실제 종단 성능 인증이라는 필드는 만들지 않는다.

θ의 각 성분은 고정 프로토콜에서 측정하는 연산 또는 전달 비용의 **모집단 p75**다. 기존 프로파일의 p75 목적을 유지한다. 같은 모델·runtime·입력·부하·경로 조건에서 같은 물리량인 경우에만 여러 배치가 같은 θ 성분을 공유한다. 상위 RPC와 포함된 하위 실행을 중복 합산하지 않는다. 개별 항목을 분리 관측할 수 없다면 관측 가능한 묶음으로 다시 정의한다.

## 비용모형과 종료 보장

배치 p의 경로 집합을 Πp라 하면

\[
L(p;\theta)=\max_{r\in\Pi_p}(a_{pr}^{\mathsf T}\theta+b_{pr}),\qquad a_{pr}\ge0.
\]

이 값은 primitive p75를 조합한 최장경로 비용모형이다. **실제 종단 지연의 평균이나 p75와 같지 않다.** 동시 실행 경합 등 모델 불일치는 별도 평가한다.

모든 측정 시점에서 참 θ를 포함할 확률이 1−δ 이상인 집합 Ut를 사용한다. 같은 θ를 양쪽 배치에 넣어

\[
D_t(p,q)=\sup_{\theta\in U_t}[L(p;\theta)-L(q;\theta)],\quad
R_t(p)=\max_{q\in F}D_t(p,q).
\]

q=p도 포함하므로 R≥0이다. 유효한 상한 \(\overline R_t(p)\le\epsilon\)이면 종료한다. 참 θ가 Ut에 포함되는 사건에서

\[
L(p;\theta^*)-\min_{q\in F}L(q;\theta^*)\le\epsilon.
\]

전역 minimax 배치를 반드시 찾아야 하는 것은 아니다. 어떤 실행 가능 배치든 전체 경쟁 배치에 대한 상한을 만족하면 된다. 이 보장은 기존 regret 원리이며 새 정리가 아니다.

예: L(p)=z+10, L(q)=z+12, z∈[0,100]이면 p가 항상 2ms 빠르다. 각 배치의 상·하한을 따로 비교한 gap은 110−12=98ms지만, 공유 z를 유지한 R(p)는 0이다. z를 더 정확히 측정할 필요가 없다. 이는 설명용 계산이며 실측 결과가 아니다.

### 작은 DAG에서 검증하는 방법

유한 구간으로 구성된 Ut에서, 고정 p,q와 p의 각 경로 r에 대해 다음 LP의 최댓값을 구한다.

\[
\max_{\theta,z}z\quad\text{s.t.}\quad
z\le(a_{pr}-a_{qs})^T\theta+b_{pr}-b_{qs}\ (\forall s\in\Pi_q),\quad\theta\in U_t.
\]

r별 결과의 최댓값이 D(p,q)다. 인증에는 solver의 유효한 **상한**과 수치 허용오차를 사용한다. maximization의 feasible primal 값은 하한이므로 종료 근거가 될 수 없다. 일반 solver의 반환 목적값에 임의 tolerance를 더한 것을 자동으로 엄밀한 상한으로 간주하지 않는다. box에서는 각 r에 대해 λs≥0, Σsλs=1인 검증된 가중치를 사용하여 min_s f_s(θ)≤Σsλs f_s(θ)의 우변을 box 끝점으로 최대화한 값을 상한으로 쓸 수 있다. 여기서 f_s는 위 LP의 우변이다. 가중치 조건과 바깥 방향 반올림을 검증할 수 없으면 기존 단순 구간 상한을 유지한다.

계산을 줄이기 위해 모든 p,q의 LP를 매회 풀지 않는다. box Ut=[l,u]에서 b=argmin L(p;u)를 추천 후보로 고르고, 동률이면 고정 ID 순서를 쓴다. 모든 q에 대한 간단한 상한 L(b;u)−L(q;l)를 먼저 구한다. ε 이하인 쌍은 통과시키고, 나머지만 LP로 정밀화한다. q=b는 정확히 0이다. 계획 시간 한도에서 멈추면 미완료 쌍의 기존 유효 상한을 유지한다. 경쟁 배치를 누락하여 인증하지 않는다.

## 구체적인 측정 선택 규칙

v0.1은 학습 없는 **배치 차이의 구간 변동량/측정 시간**을 사용한다. 현재 후보 b와 가장 큰 pairwise regret 상한을 가진 경쟁 배치 q를 고른다. 동률은 고정 ID 순서다. 유한 box의 midpoint를 m이라 하고, 항목 j만 움직이는 함수를

\[
g_j(x)=L(b;m_{-j},x)-L(q;m_{-j},x),\qquad
W_j=\max_{x\in[l_j,u_j]}g_j(x)-\min_{x\in[l_j,u_j]}g_j(x)
\]

로 정의한다. 각 비용은 구간별 선형이므로 양 끝점, b 내부 경로끼리의 교차점, q 내부 경로끼리의 교차점의 합집합에서 평가하여 Wj를 계산할 수 있다. b와 q의 비용이 서로 교차하는 점만 조사해서는 충분하지 않다. 최대 score \(W_j/\hat c_j\)의 항목을 다음 probe로 고른다. ĉj는 해당 프로토콜의 과거 probe 준비·실행 wall time으로 추정하고, 0으로 나누지 않도록 사전 지정한 양의 하한을 둔다. 고정 ID로 동률을 해소한다.

- 실제 관측은 한 번에 사전 지정 batch만큼 수집한다. 구간이 특정 비율로 줄어든다고 가정하지 않는다.
- 매 5번째 batch는 측정 가능한 모든 항목을 순환 방문한다. score가 모두 0이어도 순환 측정을 한다.
- 초기 구간에 무한대가 있으면 midpoint 규칙을 쓰지 않고 순환 측정한다. 예산이 끝나기 전 유한 구간이 생긴다는 보장은 없다.
- Wj는 다른 항목을 midpoint에 고정한 **휴리스틱**이다. 공동 불확실성의 최악 개선이나 expected value of information이 아니다. 순환 측정도 유한 예산 내 인증을 보장하지 않는다.
- 같은 항목이 공통 가산 비용이면 자동 상쇄된다. 여러 경로에 다르게 등장하면 경로 전환을 반영하므로 단순히 “공유 항목”이라는 이유로 제거하지 않는다.
- 큰 상한을 가진 q가 실제 최악 경쟁자라는 보장도 없다. acquisition의 부정확성은 별도의 전체-regret 종료 검증과 구분한다.

```text
품질·호환성 gate → F, probe, 비용모형 동결
while 측정·계획 예산이 남음:
    순차 유효 구간 U 갱신; 빈 집합이면 검증 실패로 종료
    구간이 무한하면 순환 probe 후 계속
    b 선택; 모든 경쟁 배치에 대한 regret 상한 검증
    상한 ≤ ε이면 certified=true로 반환
    차이 변동량/획득 시간 또는 순환 규칙으로 다음 probe 선택
    batch 실행; 원시 결과·timeout·실제 비용 보존
예산 소진이면 현재 실행 가능 후보와 certified=false 반환
```

무한 구간 단계에서 예산이 끝나면 관측된 점 추정으로 배치를 선택할 수 있다. 비용 관측 자체가 부족하면 사전에 검증한 고정 fallback 배치를 사용하고 근거 부족을 명시한다. 실행 가능성 확인조차 실패했으면 실행 배치를 반환하지 않는다.

## 통계 구성과 실제 성능의 경계

초기 구현용 충분조건은 고정 환경에서 primitive별 i.i.d. 표본이다. d개 항목에 대해 표본 수 n마다

\[
\alpha_{j,n}=\frac{\delta}{dn(n+1)},\quad
e_{j,n}=\sqrt{\frac{\log(2/\alpha_{j,n})}{2n}}
\]

를 쓰고 DKW band를 역변환한 [Q̂(.75−e),Q̂(.75+e)]를 사용한다. Q̂는 보간 quantile이 아니라 empirical generalized inverse다. 확률 인수가 0 이하이면 하한 0, 1 이상이면 알려진 support 상한 또는 +∞를 사용한다. 항목·표본 수 전체 union bound로 적응적 선택·중단의 실패확률을 제어한다. 과거 구간과 교집합하여 nested U를 만들되, 빈 교집합을 성공으로 취급하지 않는다.

이 구성은 보수적이며 인증까지 필요한 측정이 과도할 수 있다. [confidence sequence 문헌](https://doi.org/10.1214/20-AOS1991)은 순차 유효성의 근거이지 현재 RPC의 i.i.d. 가정을 보장하지 않는다. 시간 상관·공유 서버 간섭·환경 drift는 따로 진단한다. timeout은 버리지 않으며 검열 또는 사전 정의한 capped-latency와 실패율로 처리한다. 관측 최댓값을 알려진 support 상한으로 사용하지 않는다.

v0.1의 일반 empirical DKW 구현에 검열 시간을 완전 관측처럼 넣지 않는다. 검열이 발생한 항목은 해당 항목의 검열을 처리하는 유효한 confidence 구성을 별도로 구현·검증하기 전까지 미인증으로 반환한다. 사전 H로 capped-latency 실험을 새로 정의하는 경우에는 estimand 변경을 manifest에 명시하고 실패율을 함께 보고한다. 기존 uncensored p75 인증과 섞지 않는다.

실제 목표 T와 비용모형 사이에서 **모든 후보**에 대해 |T(p)−L(p;θ*)|≤η를 별도로 입증했다면 실제 gap≤ε+2η로 옮길 수 있다. 소수 holdout의 평균 잔차만으로 이 η를 주장하지 않는다. v0.1에서는 proxy 인증과 독립적인 실제 종단 평가를 분리한다.

## 실험 설계와 진행 기준

현재 [완주 데이터](../experiments/budget-completion-20261021.md)는 모형·관측 계약 설계에만 재사용한다. 신규 acquisition 성능이나 통계 보장을 검증한 데이터로 취급하지 않는다. 평균표에서 만든 replay는 가정된 simulation으로 표시한다.

첫 비교는 다음의 순서다.

1. **합성 검증:** 공통 비용 상쇄, 임계경로 전환, 거의 같은 배치, 간섭에 의한 모형 편향, timeout을 분리한다. 알려진 참값으로 선택 gap과 인증 실패율을 평가한다. 검증되지 않은 통계 가정의 사례도 별도로 보고한다.
2. **같은 primitive 관측 계약의 비교:** 전체 균등 측정+정확 열거, 순환/무작위 측정, 구간 폭/비용, 기존 incumbent–witness widest-gap, 이번 Wj/ĉj. 같은 종료 인증을 사용해 acquisition 효과를 분리한다. 작은 사례에선 기존 interval-split minimax 규칙도 계산 비용을 포함해 비교한다.
3. **배치 전체를 arm으로 하는 비교:** cost-aware BAI/BO 계열을 대조한다. 다른 관측 단위·목표 통계량을 맞추지 못하면 직접 동등 비교로 부르지 않는다. 원문 구현과 아이디어 기반 변형을 표시한다.
4. **별도 실측 평가:** 입력·시간 블록을 acquisition과 분리하고, 작은 F의 모든 배치를 평가해 실측 선택 손실을 추정한다. 동일 배치를 선택한 정책은 관측을 공유한다. 순서 무작위화·공유 서버 상태·원시 event와 timeout을 남긴다.

ε, δ, 최대 probe/계획 시간, 입력 분할, 반복 수 결정 방식, 실질적인 절감 기준을 **새 수집 전에** 고정한다. 결과는 품질·실패율, 인증 비율, 남은 proxy gap, 독립 종단 지연, 측정/준비/계획 wall time으로 보고한다. 여러 비용이 겹쳐 실행되면 중복 합산하지 않는다. 측정 선택 비교는 동일 예산·관측 접근 권한을 주되 선택 결과에 따른 정보 차이를 허용한다. 배치 최적화 정책 자체 비교는 동일 비용표를 제공한다.

진행 조건은 기존 간단한 측정 규칙보다 의미 있는 총 시간 절감과 독립 평가 성능 유지가 함께 관측되는 것이다. 싼 전체 프로파일링, 적은 후보, 큰 성능 차이, 짧은 사용 기간, 큰 모형 편향에서는 이점이 없을 수 있다. 계산 비용이 절약한 측정을 상쇄하거나 기존 규칙이 같은 효과를 내면 이 방향의 새 방법 주장을 중단한다.

## 신규성 경계와 구현 인계

[Wang–Boutilier 2003](https://www.cs.toronto.edu/~cebly/Papers/minimax.pdf)은 pairwise regret·LP·구간 분할 query를, [Boutilier et al. 2006](https://webdocs.cs.ualberta.ca/~daes/papers/aij06.pdf)은 incumbent/witness 선택과 anytime 상한을 다룬다. 따라서 regret·선택적 측정·solver 결합·비용 정규화 자체를 새 기여로 삼지 않는다. Wj 규칙도 아직 선행과 구별되는 신규성·이론적 이점이 확인되지 않았다.

향후 구현은 먼저 별도 합성 검증 모듈에서 진행하고 동결 실측 runner를 변경하지 않는다. 수용 기준과 허용 파일을 정한 뒤 프로젝트 지침의 Orca Codex 설계 → 공식 구독 인증 Claude 구현·테스트 → 독립 Codex 검토를 적용한다. 모델·CLI 기능을 확인하기 전 구현 워커를 실행했다고 보고하지 않는다. [작업 명세](../../.scratch/decision-focused-placement/spec.md)를 인계 진입점으로 사용한다.
