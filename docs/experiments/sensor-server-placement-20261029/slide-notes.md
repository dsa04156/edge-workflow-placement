| 네트워크 조건 | GPU 서버 실제 E2E | NPU 서버 실제 E2E | 처리만 고려 | 처리+네트워크 고려 |
|---|---:|---:|---|---|

**발표 문장:** 센서 작업 전체의 실행 서버를 실측 처리 성능과 데이터 전달시간으로 선택했다. 정상망에서는 NPU, NPU 연결이 느린 조건에서는 GPU를 선택했고, 후자에서 처리 성능만 고려한 선택보다 완료시간이 37.9% 낮게 관측됐다.
