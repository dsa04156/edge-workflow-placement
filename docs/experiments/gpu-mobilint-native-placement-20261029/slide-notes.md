**발표 문장:** 실제 GPU·NPU 실행과 전송 비용을 계측해 배치를 선택했다. 이 단기 관측에서 혼합 GNN 배치는 401.6 ms로, NPU 서버 고정 447.6 ms보다 10.3% 낮았다. Greedy와 DAG는 같은 배치를 선택했으므로 DAG 고유 우월성을 주장하지 않는다.
