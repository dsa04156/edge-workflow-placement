# 소스 구성과 출처

| 파일 | 역할 |
|---|---|
| src/prepare.py | 입력 검증, 자원 적합성, 임계 경로 비용, 정확 열거, Kubernetes 명세, CLI |
| src/analyze.py | 실패·품질 불일치 포함 관측 집계, CLI |
| src/test_prepare.py | 기존 공개 인터페이스 회귀 테스트7개 |
| src/fixture.json | 테스트 전용 합성 프로파일 |

| examples/observed-attempts.jsonl | 주 비교12건에서 집계 필드만 추출한 관측 기록 |
| evidence/ | 원본 결과·배치·감사·출처 |

Python 소스와 fixture는 원 저장소 커밋3bd5c34630eef5fde6da9a9d07a127642b033ce9에서 변경 없이 복사했다. 파일별SHA256은evidence/source-provenance.json에 있다. 새로 작성된 부분은 패키지 설명자료와 집계 예제 내보내기다. 패키지 버전1.0은 이 묶음의 버전이며 원 구현의 최초 작성일을 뜻하지 않는다.

이 패키지는 Python 표준 라이브러리만 사용한다. 원 실험에 사용한 신경망 가중치·데이터셋·컨테이너 이미지는 포함하지 않는다. 문서의 모델명은 검증 환경 설명이다. 소스 원저작자·고용/공동개발 권리관계·실제 창작/공표일은 파일 복사로 확인되지 않으므로 등록 설명서에 임의로 기입하지 않았다. 새 라이선스나 소유권 선언을 추가하지 않았다.
