|---|---|
| 프로그램 명칭 | EdgeFlow Plan — 이종 엣지 AI 워크플로 배치 계획·비교 프로그램 |
| 버전 | 1.0 (등록 준비 패키지 버전) |

| 창작 완료일·최초 공표일 | 미기입 — 실제 이력 확인 후 작성 |

## 개발 목적

이종 엣지 환경에서 작업별 연산 성능만으로 실행 위치를 결정하면 입력 및 중간 결과 전달 비용 때문에 전체 워크플로 지연이 커질 수 있다. 본 프로그램은 노드별 실행시간, 데이터 경로별 실측 전달 비용과 자원 제약을 함께 사용해 작은 AI 워크플로의 실행 위치를 계획하고, 정책별 결과를 같은 조건에서 비교할 수 있도록 한다.

## 주요 기능

1. 노드 자원·작업 실행 후보·선후 관계·입출력 전달 비용으로 구성된 프로파일의 유효성을 검사한다.
2. CPU·메모리 제약을 충족하는 배치 조합을 열거하고, 분기·합류와 최종 출력 반환 비용을 반영한 임계 경로 비용이 최소인 배치를 선택한다.
3. 연산 정보만 사용하는 정책, 전달 정보만 사용하는 정책과 결합 정책의 계획을 생성한다. 자원 기준 배치는 default-scheduler에 선택을 맡기는 명세로 출력한다.
4. 선택 노드를 node affinity로 지정한 Kubernetes Pod 명세와 입력 hash가 포함된 계획을 저장한다.
5. 실행 기록에서 워밍업을 분리하고 중복 요청을 거부하며, 실행 실패와 품질 불일치를 보존한 평균·95백분위 지연을 집계한다.

## 특징

실측 프로파일 입력을 요구하고, 자원 제약과 후보 노드를 동일하게 유지한 상태에서 비용 성분을 비교한다. 같은 노드 내부 전달 비용과 결과 반환 비용도 입력으로 받는다. 입력을 동결해 계획과 근거를 함께 남기며, 실패 요청을 성공 지연 평균에 숨기지 않고 별도 계수한다.

## 구현 및 검증 범위

등록 대상은 포함된 배치 계획·명세 생성·기록 분석 코드다. 작은 DAG의 정확 열거와 알려진 임계 경로 계산을 사용하며 새로운 최적화 알고리즘의 발명이나 저작권 귀속을 주장하는 설명은 아니다. 자체 AI 모델 학습·실시간 자동 재배포·GPU/NPU 실행·고장 복구는 이 패키지의 구현 범위에 포함되지 않는다.

완주한 실제 CPU 워크플로 비교의 저대역폭 조건에서 선택 배치의 지연 감소를 관측했다. 수치와 실험 한계는 성능검증.md를 따른다. 본 문서는 내용 초안이며 기관별 신청서 서식이나 제출 요건을 확인한 문서가 아니다.
