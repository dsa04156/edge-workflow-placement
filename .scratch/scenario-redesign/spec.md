# 실제 DAG 기반 시나리오 재설계

Status: ready-for-agent

## 목적

합성 측정 선택 실험을 실제 영상·음성·결합 DAG의 경로·제약·취득 절차에 연결한다. 사용자의 다음 단계 진행 요청에 따라 최신 문서의 정적 범위를 유지해 진행한다. 동적 재배치 재포함 결정으로 해석하지 않는다.

## 이번 산출물

- [근거 검토·재설계 초안](../../docs/research/scenario-redesign-20261021.md)
- 동결 최신 비용표·계획과 기존 알고리즘 설계를 읽어 시나리오 전제를 대조했다.
- 새 코드·클러스터 수집 없음. 기존 동결 자료와 결과 문서 변경 없음.
- [실제 DAG 측정 대응 계약](../../docs/research/actual-dag-measurement-contract-20261021.md)과 [전수 대조 JSON](primitive-audit.json): 두 조건 각 19개 유효 배치에서 경로식과 원 planner 비용 일치. 연산 9 + 전달 30 중 미사용 전달 2개를 확인했다.
- 필수 품질 검증의 연산 calibration 180관측을 공통 초기 정보로 재사용한다. 전역 공통 가산항은 0개다. 향후 구현 범위는 계약의 오프라인 어댑터 수용 기준을 따른다.

## 다음 수용 기준

우선순위 변경: 사용자가 기본 스케줄링 대 프로파일 기반 배치를 먼저 비교하도록 지시했다. [기본 비교 명세](../scheduling-baseline-comparison/spec.md)를 먼저 진행하며, 아래 선택적 측정 어댑터 작업은 후순위다.

1. 정적 유지/동적 재포함의 범위를 명시한다.
2. 실제 primitive·경로·비용 경계 대응표와 실행 가능 배치 집합을 검증한다.
3. 실제 기반 조건과 가정한 조건, 개발 조건 탐색과 독립 평가를 구분한다.
4. 단순 측정 기준선·동일 예산·전체 episode 반복 단위를 명시한다.
5. 수집 전에 허용 성능 손실, 실질적 시간 절감, 반복 수와 무작위화 일정을 동결한다.
6. 구현이 필요해지면 별도 허용 파일과 검증 기준으로 Orca 구현·독립 검토를 수행한다.
