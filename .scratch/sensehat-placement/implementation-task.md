## Data and model fixed design
Input root artifacts/sensehat-placement/discovery-20261021/history. Manifest lists source hashes. Each {temp_humidity,humidity,pressure}.json contains items, each row: deviceUid,deviceId,namespace,property,value,float64,unit,quality QUALIFIED,timeBasis SOURCE,observedAt ISO,receivedAt ISO,sourceGeneration,configurationSha256,sessionId,sequence,rawPayload JSON. ~900 rows/channel at1Hz. Validate source hashes, same channel UID/config/session/generation and strict increasing observedAt/sequence; gaps or differing metadata must be reported and not silently bridged. No interpolation, outlier deletion or padding. Keep inputs intact. Fail explicit if inadequate contiguous data (no fabricated replacement).
Use channels independently, no multichannel time alignment. Split each series raw rows by floor60% training, next20% calibration, last20% evaluation. Window8 past consecutive rows -> predict next original value. Windows cannot cross split boundaries. Training: simple learned least-squares line y=a*mean(window8)+b via statistics.linear_regression; zero-variance x uses training-target mean explicitly recorded. Freeze coefficients+training input hashes, count, first/last times; targets never enter feature/inference payload. Baseline forecast=last observed value. Do not call this anomaly detection or trained neural network. Evaluate whole held-out test segment locally per-channel MAE/RMSE vs persistence; test evaluation must not alter training or selection.
Pick cluster evaluation 3 disjoint window+target pairs per channel: first possible index, middle, last of evaluation split (ensure disjoint). warmup one calibration pair/channel. Freeze IDs before cluster execution. 9 eval+3warm requests per unique placement; at most4 unique placements =>48 workflows. Single native-network block, seeded order20261024. No injected delay/qdisc/retries to inference. Same placement shares observations. No p95/significance/throughput claim.
## Workflow
T1 receives just original window (8rows) and validates provenance/time/order -> mean and last value plus source digest metadata. T2 learned linear inference from frozen model per-channel -> forecast and last persistence. T3 packages result with units/model/input identity. Source calculates error using target only AFTER return. All-stage receipts node,PodUID,model/source hashes, input/output sha256+bytes, compute_ms; distinguish compute from nested RPC total. No fabricated load. HTTP standard library with bounded request body and explicit timeout, backend actual identity. Local CPU reference same model, cross-node numerical comparison tolerance1e-9 abs/rel. No inference automatic retry; retain errors.
