# 기존 스케줄링 대 프로파일 배치: 우선 비교

Status: ready-for-agent

## 목표

사용자가 지시한 기본 스케줄링 비교를 선택적 프로파일링보다 먼저 수행한다. 현재 단계 산출물은 [비교 설계](../../docs/experiments/scheduling-baseline-comparison-20261021.md)와 [동결 비용표 결정 대조](offline-decisions.json)다. 새 실측 완료가 아니다.

## 확정한 결정

- 실제 default-scheduler와 동일 자원·후보로 비교하기 위해 주 실험에서 인위적인 서버 슬롯2 제한을 제외한다.
- greedy EFT, HEFT-serving 변형, greedy 교환, 정확 열거 및 두 정보 제거 대조를 사용한다.
- 정확 열거를 새 알고리즘으로 부르지 않는다. 기존 문헌 원 구현과 HEFT 기반 변형을 구분한다.
- 같은 정보 알고리즘 비교와 원래 정보의 시스템 비교를 분리한다.
- 선택적 측정 어댑터 구현과 새 acquisition 알고리즘은 후순위다.

## 현 단계 검증

기존 선택기로 2조건 × 8정책의 오프라인 배치를 재계산하고 실행 가능성을 확인했다. 프로파일·소스 hash를 보존했다. 현재 10/2Mbps 모두 greedy/HEFT/교환/정확 열거가 같은 배치를 고른다. 기본 kube-scheduler의 새 관측은 없다.

## 후속 구현 경계

별도 collector/validator의 파일 소유권·테스트 명령을 Orca 인계 전에 확정한다. 기존 동결 collector·raw 자료는 수정하지 않는다. 기본 비교 계약의 구현·로컬 검증·독립 검토 이후 실제 배포 승인을 마지막 단계로 받는다. 이번 단계에서는 클러스터에 접근하거나 새 자원을 배포하지 않았다.
